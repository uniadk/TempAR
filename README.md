# TempAR
Since the normal download is hard to find and I had to go through 5 adwalls and got 2 virus links, I thought i'd just upload it here for everyone. I did NOT make this.

`TempAR.exe` is the unmodified 1.0.0.0 Windows Forms build (file version 1.0.0.0, Copyright 2010). It converts CWCheat POPS, NitePR, R4CCE, and TempAR cheat text, and it searches pointers in local memory dumps. Its assembly references are only `mscorlib`, `System`, `System.Drawing`, and `System.Windows.Forms` 2.0.0.0.

SHA-256: `3102faa2f083221d857f47951e08ccc8e853f381b06e28b8bc81c45a710932a5`

The executable targets .NET Framework 2.0. `TempAR.exe.config` keeps that runtime when it is installed, and otherwise allows .NET Framework 4 to load the program so it can start on current Windows without the optional .NET 3.5 feature.
